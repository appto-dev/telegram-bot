# 1. Введение

## 1.1 Что это

**Appto Telegram Bot Framework** (`appto-team/telegram-bot`) — пакет для Laravel, который позволяет
строить одного или нескольких Telegram-ботов внутри обычного Laravel-приложения: декларативная
регистрация команд, кнопок и текстовых триггеров, движок пошаговых диалогов, доставка апдейтов
через webhook или long polling, встроенная авторизация и `/help`.

Пакет не заменяет Bot API — он даёт удобный слой поверх него: вы описываете *что* должно
происходить в ответ на команду/кнопку/сообщение, а фреймворк берёт на себя маршрутизацию,
состояние диалогов и доставку.

## 1.2 Ключевая идея

Один класс бота = один бот. Всё, что бот умеет — команды, кнопки, диалоги, — регистрируется в
одном месте (методе `boot()` этого класса), а сама логика каждой команды/кнопки/шага живёт в
отдельном небольшом классе:

```php
final class ShopBot extends Bot
{
    protected function boot(): void
    {
        $this->onCommand('start', StartCommand::class);
        $this->onCommand('help', HelpCommand::class);
        $this->onText(GlobalReplyMarkup::CABINET_LABEL_TRIGGER, CabinetCommand::class);
        $this->onCallback('order:confirm {id}', OrderConfirmHandler::class);
    }
}
```

Читая `boot()` любого бота, вы за 10 секунд понимаете весь его функционал — это специально
задуманный эффект: конфигурация бота должна читаться как оглавление, а не как код.

## 1.3 Что берёт на себя фреймворк — и что остаётся вам

Фреймворк отвечает за:

- маршрутизацию апдейта к нужному классу (по команде, по `callback_data`, по точному тексту, по
  типу апдейта);
- состояние многошаговых диалогов между сообщениями;
- доставку апдейтов боту (webhook или long polling для разработки);
- проверку прав доступа перед выполнением хендлера, если вы её объявили;
- сборку `/help` из описаний команд;
- удобные методы «ответить в текущий чат» без ручного указания `chat_id`.

Вам остаётся:

- бизнес-логика внутри каждого хендлера/шага;
- разметка клавиатур под ваш UX;
- модели и хранилище данных приложения (сам фреймворк не хранит ничего, кроме списка ботов и
  состояния активных диалогов).

## 1.4 Требования

- PHP 8.3+
- Laravel 13+
- `appto-team/telegram-bot-cast-laravel` — типы и интерфейсы Bot API (устанавливается как зависимость
  автоматически)
