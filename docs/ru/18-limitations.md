# 18. Известные ограничения

## 18.1 `onText()` — только точное совпадение

Текстовые триггеры сравниваются с сообщением дословно (без учёта регистра и пробелов по краям),
без поддержки regex или wildcard-паттернов. Для «похожих» фраз или разбора произвольного текста
используйте команду с аргументом или шаг диалога вместо `onText()`.

## 18.2 Диалог хранит только один активный сценарий на пользователя

На пару (бот, чат, пользователь) может быть только один активный диалог одновременно. Запуск
второго диалога, пока первый не завершён/не отменён, переключит пользователя на новый сценарий
(`StepResult::switchTo()`) — параллельно они не работают.

## 18.3 Что проверять при обновлении версии Bot API

Telegram регулярно обновляет Bot API. Пакет держит клиент в актуальном состоянии — при обновлении
зависимостей стоит свериться с changelog’ом релиза Bot API и с CHANGELOG самого пакета, чтобы не
пропустить новые обязательные параметры у уже используемых вами методов.
