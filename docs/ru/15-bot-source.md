# 15. Откуда бот берёт список ботов

## 15.1 Простой способ — конфиг (по умолчанию)

```env
TELEGRAM_BOT_REPOSITORY=config
```

Список ботов — статический массив в `config/telegram-bot.php` (`bots`). Подходит для
подавляющего большинства проектов: боты известны заранее, добавляются разработчиком через код и
деплой.

## 15.2 Гибкий способ — база данных

```env
TELEGRAM_BOT_REPOSITORY=database
```

Список ботов хранится в таблице БД (токен — в зашифрованном виде). Имеет смысл, когда боты
создаются динамически — например, если ваше приложение само является SaaS-платформой, и каждый
клиент подключает своего бота через интерфейс, без участия разработчика и без деплоя.

Перед переключением опубликуйте и накатите миграцию:

```bash
php artisan vendor:publish --tag=telegram-bot-migrations
php artisan migrate
```

## 15.3 Как переключиться

Изменения ограничиваются одной переменной окружения `TELEGRAM_BOT_REPOSITORY` — код ботов
(классы-наследники `Bot`, хендлеры, диалоги) от источника списка никак не зависит и переписывать
его не нужно.
